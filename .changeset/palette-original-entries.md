The `findNearest*` functions return the matching palette entry exactly as given (RGB objects by identity), or `null` when there is no valid target or candidate. Invalid entries are skipped, palettes can be `readonly`, and the palette's element type is preserved. See the [v4 to v5 migration guide](https://github.com/sardinedev/colour/blob/main/docs/migrations/v4tov5.md).
